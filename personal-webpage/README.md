# Personal Webpage

This project is a personal webpage that showcases information about an individual, including sections for "About Me," "Research," and "Blogs." The design adheres to the specifications outlined in the Vals.ai Design System, ensuring a cohesive and visually appealing user experience.

## Project Structure

The project is organized as follows:

```
personal-webpage
├── src
│   ├── index.html          # Main HTML entry point
│   ├── sections
│   │   ├── about-me.html   # Contains the "About Me" section
│   │   ├── research.html    # Contains the "Research" section
│   │   └── blogs.html       # Contains the "Blogs" section
│   ├── styles
│   │   ├── main.css         # Main CSS styles implementing design specifications
│   │   └── design-tokens.css # Design tokens for consistent styling
│   └── scripts
│       └── main.js          # JavaScript for interactive elements
├── vals.ai-DESIGN.md        # Design specifications for the Vals.ai Design System
└── README.md                # Project documentation
```

## Setup Instructions

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd personal-webpage
   ```

3. **Open the `index.html` file in a web browser** to view the personal webpage.

## Features

- **About Me**: A section that provides personal information and background.
- **Research**: A section that showcases research projects and publications.
- **Blogs**: A section that features blog posts and articles.

## Design

This project follows the Vals.ai Design System, which includes a warm off-white/greige surface palette, a dual typeface system, and a structured layout. For more details on the design specifications, refer to the `vals.ai-DESIGN.md` file.
